# AI4SWENG KIO Pipeline Demo

A microservices demo simulating a medical report pipeline with real-time visualization (Use Case 2 - AI4SWENG).

## 🚀 Quick Start

### 1. Start the Demo
Run the following command to build and start all containers:
```bash
bash ./start_demo.sh
```

### 2. Access the UI
Open your browser and go to:
[http://localhost:8080](http://localhost:8080)

### 3. Run the Pipeline
- Click the **"Start Pipeline Process"** button.
- Watch the **Live Logs** section for real-time updates from all 5 KIO services.
- The final report will appear in the result section.

## 🛑 Stop the Demo

To stop and remove all containers:
```bash
bash ./end_demo.sh
```
